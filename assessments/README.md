| ধরন | কখন | কোথায় থাকবে |

| Module quiz | module শেষে | `assessments/<module-folder>/quiz.md` (module সম্পন্ন হলে তৈরি) |
| Practical command-line exercise | module শেষে | ঐ |
| Troubleshooting challenge | Level C lab | `labs/` |
| Architecture design exercise | Module 07, 14, 31 | ঐ |
| Stage completion exam | প্রতিটি stage শেষে | `assessments/stage-NN-exam.md` |
| Project acceptance | project শেষে | project README-র acceptance criteria |
| Interview preparation | Module 32 | `32-interview-preparation/` |
